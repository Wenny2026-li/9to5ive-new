# design/

Anything in this folder tells the build agent how this application should look. It is read on every build.

If you chose a style when this project was set up for building, `reference.html` is that style: a page of colour swatches, type samples and components. It is a STYLE reference, not a page to copy. The agent matches its palette, typography, spacing and component shapes, never its content.

If this folder holds nothing but this file, the agent chooses a sensible design itself.
